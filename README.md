# BankOfAmerica-IBM-DB2-SailFish-Migration
IBM Integrated Analytics System DB2 SailFish performed poorly and needed to be migrated to SQL Server.
Worked as a contractor. 
Project completed successfully, 

Migrated IBM Integrated Analytics System DB2 to SQL Servers in Cloud. Did System study, Analysis, Planning. Did Data mapping, transformation logic and rules, enriched and enhanced data, validated and reconciled data, did pre and post migration record counts, data integrity, open transactions and historical data archival. Did several mock drills with cross functional teams at nights and weekends.

Implemented Trino Views and Feeds to SQL Server using SSIS, ETL ELT. 
Used Windows Shell, PowerShell and Autosys to schedule them. Used Jira, CI CD in Agile environment. 
Did Query and Index Tuning, converted complex stored procedures converted views to use CTE. 
Trained Junior Developers and DBAs. Set Coding Standards.
